# HU-02.1: Ver catálogo de productos

**Como** visitante o cliente
**Quiero** ver el catálogo de productos del taller
**Para** encontrar lo que necesito comprar

## Criterios de aceptación
- Puedo ver una lista de productos con imagen, nombre y precio.
- Puedo filtrar por categoría.
- Puedo buscar productos por nombre.
- Los productos sin stock se marcan como "agotado" pero siguen siendo visibles.
- No necesito iniciar sesión para navegar el catálogo.
