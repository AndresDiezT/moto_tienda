# HU-02.4: Elegir método de entrega en el checkout

**Como** cliente
**Quiero** elegir si retiro mi pedido en el taller o lo recibo a domicilio
**Para** decidir la opción que más me convenga

## Criterios de aceptación
- En el checkout puedo elegir entre "Retiro en tienda" y "Envío a domicilio".
- Si elijo domicilio, debo indicar una dirección de envío.
- Si elijo domicilio, se muestra un costo de envío (tarifa fija en esta fase de demo).
- Si elijo retiro en tienda, no se cobra costo de envío.
- Debo estar autenticado para llegar a este paso (el carrito puede armarse sin sesión, pero el checkout requiere login).
