# HU-02.9: Gestionar mis direcciones de envío

**Como** cliente
**Quiero** guardar una o varias direcciones de envío en mi cuenta
**Para** no tener que escribirla de nuevo cada vez que compro a domicilio

## Criterios de aceptación
- Puedo agregar una dirección con dirección, ciudad y una referencia opcional.
- Puedo ver la lista de mis direcciones guardadas.
- Puedo editar o eliminar una dirección propia.
- No puedo ver ni modificar direcciones de otro cliente.
- Al elegir "envío a domicilio" en el checkout (HU-02.4), puedo seleccionar entre mis direcciones guardadas o agregar una nueva ahí mismo.
- Una dirección ya usada en un pedido no se puede eliminar (para no perder la trazabilidad de pedidos anteriores), solo dejar de usarse hacia adelante.
