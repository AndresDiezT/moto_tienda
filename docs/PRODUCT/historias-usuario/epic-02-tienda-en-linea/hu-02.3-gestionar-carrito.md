# HU-02.3: Gestionar carrito de compras

**Como** cliente
**Quiero** agregar, editar y quitar productos de mi carrito
**Para** armar mi pedido antes de pagar

## Criterios de aceptación
- Puedo ver los productos agregados, con cantidad, precio unitario y subtotal.
- Puedo cambiar la cantidad de un producto (respetando el stock disponible).
- Puedo eliminar un producto del carrito.
- El carrito muestra el total a pagar, actualizado en tiempo real.
- El carrito persiste mientras navego el sitio (no se pierde al cambiar de página).
