# HU-02.2: Ver ficha de producto

**Como** visitante o cliente
**Quiero** ver el detalle de un producto
**Para** decidir si lo compro

## Criterios de aceptación
- Puedo ver galería de imágenes, descripción, precio y disponibilidad de stock.
- Si hay stock, puedo elegir cantidad y agregar al carrito desde esta vista.
- Si no hay stock, el botón de agregar al carrito está deshabilitado.
