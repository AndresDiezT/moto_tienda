# HU-02.8: Gestionar pedidos de la tienda

**Como** administrador del taller
**Quiero** ver y actualizar el estado de los pedidos de la tienda
**Para** operar el cumplimiento de las ventas (preparación, entrega)

## Criterios de aceptación
- Puedo ver la lista de todos los pedidos, con filtro por estado.
- Puedo ver el detalle de un pedido: productos, cliente, método de entrega, estado de pago.
- Puedo actualizar el estado del pedido (ej. en preparación → listo para retiro/enviado → entregado).
- Puedo ver si el pedido tiene factura simulada generada.
