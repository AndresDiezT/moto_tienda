# HU-03.7: Pagar el servicio en línea

**Como** cliente
**Quiero** pagar el costo de la reparación desde el sitio, una vez aprobada la cotización
**Para** no tener que pagar presencialmente en el taller

## Criterios de aceptación
- El pago solo está disponible después de aprobar la cotización (HU-03.6).
- Al confirmar el pago, soy dirigido al flujo de Mercado Pago (modo sandbox en esta fase).
- Si el pago es aprobado, la orden queda marcada como pagada y se genera una factura simulada (ver Épica 5).
- Si el pago falla o se cancela, puedo reintentarlo.
- El estado de pago de la orden es visible tanto para el cliente como para el taller.
