# HU-03.1: Registrar mi vehículo

**Como** cliente
**Quiero** registrar los datos de mi moto
**Para** que el taller pueda asociar mis órdenes de servicio a ella

## Criterios de aceptación
- Puedo registrar marca, modelo, año y placa de mi vehículo.
- Puedo registrar más de un vehículo si tengo varios.
- Puedo ver la lista de mis vehículos registrados.
- La placa no se puede duplicar dentro de mi cuenta.
