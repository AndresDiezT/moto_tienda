# HU-03.2: Crear orden de servicio y asignar mecánico

**Como** administrador del taller
**Quiero** crear una orden de servicio para el vehículo de un cliente y asignarle un mecánico
**Para** empezar a darle seguimiento a la reparación/mantenimiento

## Criterios de aceptación
- Puedo crear una orden de servicio eligiendo un vehículo (y su dueño) ya registrado.
- Puedo describir el problema/motivo de ingreso.
- Puedo asignar un mecánico de la lista de mecánicos activos.
- La orden queda creada con estado inicial "Recibido".
- Puedo reasignar la orden a otro mecánico más adelante si es necesario.
