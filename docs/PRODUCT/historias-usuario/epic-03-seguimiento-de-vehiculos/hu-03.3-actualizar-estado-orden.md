# HU-03.3: Actualizar el estado de una orden de servicio

**Como** mecánico asignado (o admin)
**Quiero** actualizar el estado de una orden de servicio con una nota y fotos opcionales
**Para** dejar constancia del avance del trabajo y que el cliente lo vea

## Criterios de aceptación
- Puedo cambiar el estado de la orden siguiendo la secuencia definida (Recibido → En diagnóstico → Presupuesto enviado → Aprobado → En reparación → Control de calidad → Listo para entrega → Entregado).
- Puedo agregar una nota de texto al actualizar el estado.
- Puedo adjuntar una o más fotos al actualizar el estado.
- Cada actualización queda registrada en el historial/timeline de la orden, sin poder editarse ni borrarse después (solo agregar nuevos eventos).
- Un mecánico solo puede actualizar órdenes que tiene asignadas; el admin puede actualizar cualquiera.
