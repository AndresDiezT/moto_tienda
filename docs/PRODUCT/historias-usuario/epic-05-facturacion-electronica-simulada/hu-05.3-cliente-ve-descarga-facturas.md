# HU-05.3: Ver y descargar mis facturas

**Como** cliente
**Quiero** ver y descargar mis facturas, tanto de compras como de servicios
**Para** tener mi comprobante de pago

- Puedo ver una lista de todas mis facturas (tienda y servicios) en un solo lugar.
- Puedo descargar el PDF de cualquiera de mis facturas.
- Solo veo mis propias facturas, nunca las de otro cliente.
