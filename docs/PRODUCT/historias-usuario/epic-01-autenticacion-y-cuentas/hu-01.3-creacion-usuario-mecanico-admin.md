# HU-01.3: Creación de usuario mecánico

**Como** administrador del taller
**Quiero** crear cuentas de usuario para mis mecánicos
**Para** que puedan iniciar sesión y actualizar el estado de las órdenes que les asigne

## Criterios de aceptación
- Desde el panel admin puedo crear un usuario con nombre, correo, teléfono y rol `mechanic`.
- El sistema genera o solicita una contraseña inicial para el mecánico.
- Los roles `mechanic` y `admin` **no** se pueden crear desde el formulario público de registro (HU-01.1), solo desde el panel admin.
- Puedo ver la lista de mecánicos existentes.
- Puedo desactivar un usuario mecánico (deja de poder iniciar sesión) sin borrar su historial de órdenes atendidas.
