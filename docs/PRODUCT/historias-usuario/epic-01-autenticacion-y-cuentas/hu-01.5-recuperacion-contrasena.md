# HU-01.5: Recuperación de contraseña

**Como** usuario que olvidó su contraseña
**Quiero** poder restablecerla
**Para** no quedar bloqueado fuera de mi cuenta

## Criterios de aceptación
- Desde el login puedo pedir "olvidé mi contraseña" ingresando mi correo.
- Se genera un enlace/token de restablecimiento válido por tiempo limitado.
- Con el enlace puedo definir una nueva contraseña.
- El token no se puede reutilizar una vez usado o expirado.

## Notas
En esta fase de demo, el envío del enlace puede simularse (ej. mostrarlo en pantalla o loguearlo) en vez de enviar un correo real, salvo que ya se integre un proveedor de email transaccional — ver `docs/01-requerimientos-y-arquitectura.md` sección 0.
