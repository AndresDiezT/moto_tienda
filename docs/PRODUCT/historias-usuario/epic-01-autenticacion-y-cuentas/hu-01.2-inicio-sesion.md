# HU-01.2: Inicio de sesión

**Como** usuario registrado (cliente, mecánico o admin)
**Quiero** iniciar sesión con mi correo y contraseña
**Para** acceder a las funciones que me corresponden según mi rol

## Criterios de aceptación
- Un mismo formulario de login sirve para los 3 roles.
- Tras iniciar sesión, soy redirigido a la vista correspondiente a mi rol (cliente → tienda/mis vehículos, mecánico → sus órdenes asignadas, admin → panel).
- Si las credenciales son incorrectas, se muestra un mensaje de error genérico (sin indicar si el correo existe o no).
- La sesión se mantiene activa mientras no cierre sesión o expire el token.
- Existe una opción de "cerrar sesión" visible en todo momento estando autenticado.
