# PRODUCT

Definición de producto desde la perspectiva del usuario: épicas e historias de usuario.

- **`epicas/`** — un archivo por épica (ej. `epic-02-tienda-en-linea.md`), con su objetivo, roles involucrados, alcance y fuera de alcance. Describe el objetivo de negocio, no el detalle técnico.
- **`historias-usuario/`** — una carpeta por épica (mismo nombre que su archivo en `epicas/`), y dentro de cada carpeta, todas las historias de usuario de esa épica. Formato de cada historia: `Como [rol] quiero [acción] para [beneficio]`, con sus criterios de aceptación.

Cada historia debe poder trazarse a la épica a la que pertenece (misma carpeta = misma épica).
