# ARCHITECTURE

Documentación técnica viva del sistema: diagramas, modelo de datos detallado, componentes, integraciones externas y cómo encajan entre sí.

A diferencia de `ADR/` (que registra decisiones puntuales en el tiempo), aquí vive la descripción **actual** del sistema — se actualiza a medida que la arquitectura cambia.

Contenido esperado (se irá agregando):
- Diagrama de componentes / módulos.
- Modelo de datos detallado (entidades, relaciones, esquema).
- Integraciones externas (Mercado Pago, facturación electrónica, storage de archivos).
- Decisiones de infraestructura (hosting, base de datos, variables de entorno).
