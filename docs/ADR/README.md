# ADR — Architecture Decision Records

Registro de decisiones de arquitectura importantes: qué se decidió, por qué, qué alternativas se consideraron y qué consecuencias trae.

Una decisión por archivo, numerada: `0001-titulo-corto.md`, `0002-otro-titulo.md`, etc.

Plantilla sugerida por ADR:

```markdown
# NNNN. Título de la decisión

## Estado
Propuesta | Aceptada | Reemplazada por ADR-XXXX | Obsoleta

## Contexto
¿Qué problema o pregunta motiva esta decisión?

## Decisión
¿Qué se decidió?

## Alternativas consideradas
¿Qué otras opciones se evaluaron y por qué no se eligieron?

## Consecuencias
¿Qué implica esta decisión hacia adelante (positivo y negativo)?
```
